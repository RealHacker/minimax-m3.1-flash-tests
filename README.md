# Minimax-m3.1-Flash tests

This is the code for the 3 tests I did on Minimax-m3.1-Flash. The testing process has been recorded here: 
https://www.zhihu.com/question/2087553534740914468/answer/2088983213712598140 

- markdown-parser is the C codebase for a markdown parser MiniMax wrote to solve CATHY-P03 coding problem.
- ramen is the Ramen noodle chain website MiniMax implemented. The online version: https://noodle9.vercel.app/
- waldo contains the problem of Finding Waldo, which MiniMax model solves by drawing a red rectangle around the character.
